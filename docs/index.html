    Admin › Security

    Built for files you can't put in someone else's cloud.

    The controls security teams ask for, a code base audited against the attacks that target file sharing, and a pipeline that keeps checking it.

    • Two-factor authenticationTOTP with single-use recovery codes. Turning it off needs the password and a code.
    • Roles, groups and per-path rulesGranular permissions, with allowed paths checked segment by segment.
    • Full audit trailEvery login, preview, share and file action, filterable and exportable to CSV.
    • Session control and quotasLog out everywhere, admin revoke, per-user storage limits.
    • Hardened by defaultStrict CSP, Secure and SameSite cookies, rate-limited logins and links, path-traversal and symlink protection.
    • Your data stays putFiles live on your disk as plain files. No third-party processor.

    October 2026 audit: every finding fixed

    ~ › docker compose up -d

    Live in three steps.

    One distroless image, a few environment variables and no external database to manage. Run it on a VPS, a NAS or in your data center.

    # docker-compose.yml
services:
  fileflow:
    image: fileflow:latest
    ports: ["8080:8080"]
    environment:
      ADMIN_USERNAME: admin
      ADMIN_PASSWORD: ${ADMIN_PASSWORD}
      MAX_UPLOAD_MB: 50000
      ROOT_DIR: /data
      CONFIG_DIR: /config
    volumes:
      - ./data:/data
      - ./config:/config

$ docker compose up -d
    1. Pull and configureSet an admin password and the upload limit. The JWT secret is generated on first start.
    2. Run it anywhereSQLite-backed, single container, with a built-in health check.
    3. Invite your teamCreate users and groups, set quotas, and start sharing.
